## Причины одной строкой
- Порог выше GPA 3.09: Imperial 3.6, King's College London 3.57, LSE 3.5, Manchester 3.33, UCL 3.3, Bristol 3.3, Birmingham 3.4 (Bakalavr), Edinburgh 3.25, Glasgow 3.4 (International Business), Durham 3.4 (прямой вход; подготовка ISC от 3.0), St Andrews 3.33.
- Exeter: таблица для Казахстана только по пятибалльной шкале (2:2 = 3.9–4.29, 2:1 = 4.3–4.69), эквивалент для шкалы 4.0 Exeter не называет. Другие вузы приравнивают 3.0/4.0 к 4.0/5.0 (Surrey), значит, скорее всего GPA 3.09 проходит на 2:2, но это не подтверждено. Вернуть в Match после подтверждения у Exeter или по пятибалльным оценкам в дипломе.
- Oxford и Cambridge: порог не проверялся. Southampton, Cardiff: порог для Казахстана не найден. Queen's Belfast вернулся в список 22.11.2026 (2:2 = 3.0/4.0, International Business просит 2:2). Liverpool вернулся в список 22.11.2026: на странице Liverpool для Казахстана минимум для магистратуры 2.9/4.0; прежняя запись «первый класс = 3.75» была ошибкой, 3.75 это тот же минимум по шкале 5.0.

## Southampton (22.11.2026, не записан по правилу GPA)

Название есть в перечне Болашака под кодом 1.23. Southampton в списке Болашака (номер 53).
Порог GPA (проверено на сайте 22.11.2026): страница Southampton для Казахстана о магистратуре даёт три полосы без названия шкалы (1st = 1.59 и ниже, 2:1 = 2.0–2.5, 2:2 = 2.51–3.49); шкала перевёрнутая (меньше = лучше), к GPA 4.0 она не относится.
